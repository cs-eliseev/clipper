# Clipper

[English](README.md) · **Русский**

Браузерный инструмент, который собирает вертикальный клип из обложки и трека.
Вы выбираете отрезок на волне, ловите кадр мышью, добавляете надписи, движение
и полосу волны — на выходе готовый bash-скрипт, который рендерит файл через
ffmpeg.

![Clipper](docs/screenshot.png)

## Быстрый старт

```bash
git clone https://github.com/cs-eliseev/clipper.git
cd clipper
xdg-open index.html        # macOS: open index.html
```

Дальше:

1. Перетащите WAV или MP3 на дорожку, обложку — на кадр.
2. Протяните по волне и выберите отрезок — берите хук, а не вступление.
3. Поймайте кадр: перетаскивание двигает картинку, колесо приближает.
4. Добавьте надписи и движение в панели справа.
5. Нажмите **Скрипт**, скопируйте и запустите из каталога проекта:

```bash
bash clip.sh              # или вставьте скрипт прямо в терминал
```

Для рендера нужны `ffmpeg` и `python3` — браузерной части не нужно ничего.

```bash
ffmpeg -version && python3 --version
```

## Три раскладки

Переключатель в шапке меняет только расстановку одного и того же редактора.
Клип, панель и скрипт общие.

| Раскладка | Расстановка | Когда удобна |
| --- | --- | --- |
| **Волна** | дорожка полосой сверху, кадр по центру, настройки справа | работа от трека: сначала слышно отрезок |
| **Кадр** | кадр по центру, дорожка под ним, настройки справа | работа от картинки: кадру достаётся больше места |
| **Шаги** | панель слева, первый шаг — «Трек и отрезок», кадр справа | пройти клип по шагам |

## Что умеет

- **Отрезок на волне** — протянуть, чтобы выделить, внутри выделения — двигать,
  за край — менять границу. `Пробел` — воспроизвести звук вместе с превью.
- **Живое превью кадра**, которое повторяет расчёт движения из `render-clip.py`:
  что видно здесь, то и окажется в готовом файле.
- **Прямое управление.** Картинку, полосу волны и надпись можно тянуть прямо по
  кадру; колесо приближает картинку, расширяет полосу или поворачивает надпись.
  Нужный блок панели открывается сам.
- **Анимация** — наезд, отъезд, четыре панорамы и затемнение. Зум, горизонталь и
  вертикаль — независимые дорожки, поэтому наезд и панорама идут одновременно;
  чтобы по очереди, разведите интервалы. Конфликты по одной оси помечаются.
- **Текст** со шрифтом, цветом, прозрачностью, наклоном, интервалом и скоростью
  появления и ухода; `|` — перенос строки.
- **Дорожки под волной** — шкала секунд отрезка (клик перематывает), головка
  текущего момента и по дорожке на кадры, анимацию, текст и спектр. Анимацию
  и текст можно раскрыть — по строке на каждый элемент.
- **Любое значение ползунка** вводится с клавиатуры: щёлкните по числу справа,
  наберите, Enter. Стрелки ↑↓ шагают на деление, с Shift — на десять.
- **Спектр** — десять видов, от осциллограмм до вектороскопа, с цветом,
  прозрачностью и обводкой.
- **Размер кадра** 9:16, 1:1, 4:5, 16:9 или любая своя пара.
- **Кадры и превью** — картинка-вступление и картинка-концовка со своей
  длительностью и переходом: просто сменится, проявится, отъедет, отъедет и
  растает, вырастет и растает. Переход идёт поверх клипа и не укорачивает его;
  трек под заставками продолжает играть.
- **Превью в проводнике** (в том же блоке) — миниатюра mp4: кадр готового клипа на нужной
  секунде или своя картинка, вшивается в файл как обложка и по желанию
  кладётся рядом отдельным `.jpg`.
- **Список клипов** — отложите несколько и получите один скрипт на все.
- **Языки и темы** — русский и английский в комплекте, свои подключаются
  файлом прямо в интерфейсе (⚙ в шапке) или кладутся рядом с `index.html`.

Раскладка, открытые блоки, размер кадра, пути, язык и тема запоминаются между
сессиями (`localStorage`).

## Рендер

`render-clip.py` читает описание клипа из файла или со стандартного ввода и
вызывает ffmpeg:

```bash
./render-clip.py clip.json
./render-clip.py < clip.json
./render-clip.py --print-cmd clip.json    # показать команду ffmpeg, не запуская
```

Описание — обязательны только `image`, `audio` и `out`:

```json
{
  "image": "cover.jpg",
  "audio": "track.wav",
  "frame": [1080, 1920],
  "start": 45.0,
  "duration": 15.0,
  "out": "clip01.mp4",
  "img": { "scale": 1.0, "x": 0.5, "y": 0.5, "fit": "cover" },
  "smooth": 3,
  "anims": [
    { "type": "zoomin",   "speed": 1.0, "from": 0, "to": 7.5 },
    { "type": "panright", "speed": 1.0, "from": 7.5, "to": 15 },
    { "type": "dim", "value": 0.45, "from": 2, "to": 10, "fadeIn": 0.5, "fadeOut": 0.5 }
  ],
  "wave": {
    "on": true, "type": "wave-cline", "freq": 0.5,
    "x": 0.5, "y": 1620, "w": 1080, "h": 240,
    "color": "#ffffff", "alpha": 0.85,
    "outline": { "on": true, "color": "#000000", "size": 2 }
  },
  "texts": [
    { "text": "первая строка|вторая", "x": 540, "y": 960, "angle": -4,
      "size": 64, "color": "#ffffff", "font": "/путь/шрифт.ttf",
      "from": 0, "to": 15, "fadeIn": 0.6, "fadeOut": 0.6 }
  ],
  "intro": { "image": "title.png", "duration": 2.0, "anim": "slidefade",
             "dir": "left", "animDur": 0.6, "audioFade": 0.5 },
  "outro": { "image": "credits.png", "duration": 3.0, "fit": "contain",
             "anim": "fade", "animDur": 0.8, "audioFade": 1.0 },
  "thumbnail": { "mode": "frame", "time": 4.5, "save": true }
}
```

Заставки раздвигают общую шкалу: `duration` — сколько держится кадр, под
вступлением звучат секунды трека *до* отрезка, под концовкой — *после*.
Переходы: `cut`, `fade`, `slide`, `slidefade`, `zoom`; `dir` — сторона для
сдвига. Миниатюра — `frame` (кадр готового клипа на секунде `time` по общей
шкале) или `image` (своя картинка); `save` кладёт рядом `.jpg`. GNOME и KDE
показывают встроенную обложку, Windows и macOS обычно берут первый кадр
видео — то есть вступление.

Все поля описаны в докстринге модуля: `./render-clip.py --help`.

### make-clip.sh

Маленький CLI на один клип, без редактора:

```bash
./make-clip.sh -i обложка.jpg -a трек.wav -s 45 -d 15 -m wave -o clip01.mp4
```

## Тесты

Зависимостей нет — всё на встроенных инструментах:

```bash
npm test          # 62 теста рендера, стандартный unittest
npm run smoke     # прогон интерфейса в настоящем браузере
npm run check     # то и другое
```

или без npm: `python3 -m unittest discover -s tests -v`.

**`tests/test_render_clip.py`** проверяет `render-clip.py` — там ошибка стоит
дороже всего: неверный фильтр даёт битое видео, а увидеть это можно только
после долгого рендера. Сам ffmpeg не запускается, сравнивается то, что ему
передаётся: выражения зумпана, слои затемнения, фильтры всех десяти видов
полосы, экранирование надписей, размер кадра, слои заставок и общая шкала
звука под ними, команды миниатюры, и сквозной прогон `--print-cmd` вместе с
обработкой ошибок.

**`npm run smoke`** открывает страницу в headless-браузере и проходит путь
пользователя: перетащить трек и обложку, выбрать отрезок, переключить
раскладки, включить полосу, добавить надпись и движение, поставить заставки
и миниатюру, собрать скрипт, сменить язык и тему.

Браузерная часть пока покрыта только этим прогоном: её логика лежит в общей
области видимости и по-настоящему тестируется только вместе со страницей.
Разложить её по модулям, как это сделано в [Cropper](https://github.com/cs-eliseev/cropper), — отдельная
работа; после неё сюда добавятся модульные тесты.

## Пути

Браузер не сообщает полный путь к перетащенному файлу, поэтому скрипт собирает
пути из поля **Каталог с файлами** и имён файлов. Если трек или обложка лежат в
подпапке — допишите её к имени. **Путь к рендеру** — то, что вызовет скрипт:
`./render-clip.py`, если рабочий каталог и есть этот репозиторий.

## Шрифты

Список шрифтов указывает на обычные пути Linux (DejaVu, Liberation, FreeFont).
На другой системе поправьте `fonts` в `config.js` — рендеру нужен любой
читаемый путь к `.ttf`:

```js
fonts: [
  { n: 'Helvetica', f: '/System/Library/Fonts/Helvetica.ttc' }
]
```

## Свои языки

Язык переключается в ⚙ в шапке. Там же две кнопки:

- **Файл…** — подключить свой словарь с диска, `.json` или `.js`;
- **Шаблон** — скачать текущий словарь целиком, чтобы перевести его.

Обычный порядок: скачали шаблон → перевели строки → загрузили обратно.
Словарь остаётся в браузере и подхватывается при следующем запуске.

Чтобы язык был в наборе с самого начала, положите файл в `lang/` и
подключите рядом с остальными в `index.html`:

```html
<script src="lang/es.js"></script>
```

Формат словаря — один вызов:

```js
App.lang({
  code: 'es',
  name: 'Español',
  dir: 'ltr',                 // 'rtl' для арабского или иврита
  strings: { appTitle: 'Montaje de clips', blockImage: 'Cuadro' }
});
```

Тот же объект без обёртки — готовый `.json` для загрузки через ⚙.
Ключи, которых в переводе нет, берутся из запасного языка (`fallbackLang`
в `config.js`), поэтому неполный перевод ничего не ломает.

## Свои темы

Тема — это файл с токенами и больше ничем: `themes/dark.css` показывает
весь набор с пояснениями. Токены одинаковые у Clipper и Cropper, так что
тему можно переносить между ними как есть.

Файл, загруженный через ⚙ → Тема → Файл…, **дополняет** выбранную тему, а не
заменяет её — достаточно переопределить несколько токенов:

```css
:root {
  --acc: #2f7fbf;
  --wave-peak: #6f8fa8;
}
```

Готовую тему удобно положить рядом и объявить в `config.js`:

```js
App.theme({ id: 'sand', name: 'Песок', href: 'themes/sand.css' });
```

Кадр остаётся тёмным при любой теме — это содержимое клипа, а не интерфейс,
и превью не должно врать о том, что получится в файле.

Разметка и размеры живут в `css/app.css`, цветов там нет вообще. Классы по
БЭМ, поэтому из своего файла легко переопределить и отдельный блок:
`.track__clip--anim { … }`.

## Настройки (config.js)

| Ключ | Что задаёт |
| --- | --- |
| `lang`, `fallbackLang` | язык при первом запуске (`auto` — по браузеру) и запасной |
| `theme` | тема при первом запуске |
| `variant`, `variants` | стартовая раскладка и список доступных |
| `blocks.order`, `.hidden`, `.open` | порядок блоков панели, что спрятать, что раскрыть |
| `formats`, `frame` | форматы кадра и размер по умолчанию |
| `lengths`, `duration`, `minDuration`, `maxDuration` | быстрые длины отрезка и границы |
| `renderer`, `baseDir`, `outName` | что подставляется в скрипт |
| `fonts`, `defaultFont` | шрифты надписей |
| `previewLong` | длинная сторона превью-канваса |

Выбор пользователя всегда сильнее: раскладка, язык, тема и состояние панели
остаются в браузере. Кнопка **Сбросить своё** в ⚙ возвращает всё к `config.js`.

## Из чего состоит

```
index.html          разметка — только БЭМ-классы, без инлайновых стилей
config.js           настройки: язык, тема, блоки, форматы, шрифты, пути
css/app.css         блоки и размеры — ни одного цвета, всё через токены
themes/dark.css     тёмная тема: полный список токенов
themes/light.css    светлая тема
lang/ru.js          русский словарь
lang/en.js          английский словарь
js/registry.js      реестр расширений: языки, темы, настройки
js/i18n.js          выбор языка и подстановка строк
js/theme.js         темы и токены для отрисовки на канвасе
js/state.js         константы, описание клипа, состояние интерфейса
js/audio.js         чтение трека, пики, прослушивание
js/preview.js       кадр: отрисовка и мышь
js/timeline.js      волна, отрезок, дорожки слоёв
js/inspector.js     ползунки панели, собранные из данных
js/frames.js        заставки до и после клипа, миниатюра для проводника
js/queue.js         список клипов и скрипт
js/colorpicker.js   пипетка
js/app.js           раскладки, панель, шапка
render-clip.py      рендер (ffmpeg)
make-clip.sh        CLI на один клип
docs/               скриншоты
```

Стили по БЭМ: `блок`, `блок__элемент`, `блок--модификатор`. Каждое правило
начинается с класса, поэтому разметку и стили можно читать рядом.
